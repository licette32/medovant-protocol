## How to use

1. Copy [TEMPLATE.md](./TEMPLATE.md) for a new `RES-XX` entry.
2. Fill **Question** from the issue's Background + Goal before researching.
3. Record every source in **Sources**; cite findings as `[S1]`, `[S2]`.
4. Set an explicit **Confidence** level (`High` / `Medium` / `Low` / `Not assessed`).
5. Close the loop: link the document back in its GitHub issue
   (acceptance criterion of [#80](https://github.com/licette32/medovant-protocol/issues/80)):
   paste `docs/research/RES-XX-<slug>.md` into the corresponding issue.

## Convention

- One file per research question: `RES-XX-<slug>.md`.
- Findings live in each `RES-XX` document (out of scope for RES-00 / #80).
